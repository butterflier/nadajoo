# 나다주앱

학원 부원장(스케줄 관리 담당자)이 쓰는 개인수업 스케줄 관리 앱입니다.
선생님들의 시간표를 짜고, 학생별 개인수업 잔여 시간을 관리하고,
완성한 시간표를 **PNG로 내려받아** 카카오톡·슬랙으로 선생님께 보냅니다.

- **레포** — `butterflier/nadajoo` (브랜치 `main`)
- **Worker 이름** — `nadajoo`
- **원본 데이터** — Notion 데이터베이스 둘
  - [나다주 학생](https://app.notion.com/p/277ed59ba9d4414c87787f3b57eb963b) `277ed59b-a9d4-414c-8778-7f3b57eb963b`
  - [나다주 수업](https://app.notion.com/p/bbcce3ecbea34abdadec72c5f82620dd) `bbcce3ec-bea3-4abd-adec-72c5f82620dd`

> 개인수업 시간표 앱(`butterflier/schedule`)과는 **별개의 앱**입니다.
> 코드도 Worker도 Notion 데이터베이스도 공유하지 않습니다.

---

## ⚠️ 제일 먼저 알아야 할 것

### 조회에도 비밀번호가 필요합니다

시간표 앱은 링크만 알면 누구나 볼 수 있었지만, 이 앱은 **학생 연락처**를 다룹니다.
그래서 `/api/*` 전부가 `SHARED_PASSWORD` 로 잠겨 있습니다. 링크만으로는 아무것도 안 보입니다.

비밀번호는 브라우저 `sessionStorage` 에 남아 탭을 닫으면 사라집니다.

### 잔여 시간은 저장하지 않습니다

학생에게 저장하는 건 **총 시간** 하나뿐입니다. 잔여는 매번 계산합니다.

```
사용 = 날짜가 오늘 이하인 수업들의 길이 합    ← "수업일 00시 00분에 차감"
예정 = 날짜가 오늘보다 뒤인 수업들의 길이 합   ← 아직 안 깎인 몫
잔여 = 총 시간 − 사용
```

이렇게 해 두면 숫자가 어긋날 일이 없고, **등록하는 순간 차감**으로 바꾸고 싶어지면
`src/model.ts` 의 `balanceOf()` 안 비교 한 줄(`l.date <= today`)만 고치면 됩니다.

잔여가 모자라도 **등록을 막지는 않습니다** — 경고만 띄우고 판단은 부원장이 합니다.
잔여가 음수면 화면에 `-2시간` 처럼 빨갛게 보여 초과분을 숨기지 않습니다.

## 이 앱이 하는 일

### 화면 셋

| 탭 | 보이는 것 |
| --- | --- |
| `선생님별` | 선생님 한 분의 **월~일 7일** 주간 시간표 |
| `날짜별` | 하루치를 **선생님별 칸**으로 나란히 |
| `학생 관리` | 이름·연락처·총/사용/잔여/예정 시간·메모 |

격자는 **08:00 ~ 24:00**, 가로선은 30분 단위입니다.

- 빈 칸을 누르면 그 시각으로 등록 창이 열립니다 (30분 단위로 내림, 기본 2시간).
  그 칸의 **선생님과 날짜가 미리 채워집니다**
- 블록을 누르면 수정 창
- 블록은 3단 — 위 `시간`, 가운데 `학생명`(굵게), 아래 `수업종류`
- 겹치는 블록은 폭을 나눠 나란히 놓습니다

### 선생님과 수업종류

선생님과 수업종류는 코드에 고정돼 있습니다 (`src/model.ts` 맨 위).

- 선생님 — `타카하시` `가와구치` `김혜진` `스도` `표지연`
- 수업종류 — `본고사`(파랑) `면접`(초록) `지유서`(황토)

색은 수업종류를 따릅니다. 블록만 보고 무슨 수업인지 알아볼 수 있습니다.

**늘리거나 이름을 바꾸려면** `src/model.ts` 의 `TEACHERS` / `KINDS` 를 고치고,
Notion 쪽 `선생님` / `수업종류` 선택 속성의 항목도 **같은 이름으로** 맞춰야 합니다.

### 겹칠 때

수업을 저장할 때 서버가 두 가지를 봅니다.

| 겹침 | 안내 | 확인하면 |
| --- | --- | --- |
| **학생** 겹침 — 그 학생이 같은 시간에 이미 잡혀 있다 | `가와구치T 면접 수업이 이미 등록되어 있습니다. 수정할까요?` | 기존 등록을 **지우고 옮겨옵니다** |
| **선생님** 겹침 — 그 선생님이 같은 시간에 다른 학생을 받고 있다 | `가와구치 선생님은 그 시간에 김하늘 학생 수업이 있습니다. 그래도 등록할까요?` | 둘 다 남깁니다 (격자에 나란히 보입니다) |

### 반복 등록

등록 창에서 `2주 / 4주 / 8주 / 12주` 를 고르면 그 주 수만큼 **같은 요일·같은 시각에**
한 건씩 만듭니다. 수업 자체는 전부 하루짜리라, 한 주만 지우거나 옮겨도 나머지는 그대로입니다.

### PNG

`PNG 저장` 을 누르면 지금 보고 있는 시간표를 파일로 내려받습니다.

화면을 캡처하는 게 아니라 **캔버스에 2배 해상도로 직접 그립니다.** 캡처 라이브러리는
웹폰트와 CSS 격자에서 자주 어긋나고 글자가 뭉갭니다. 카톡·슬랙으로 그대로 보내도 읽힙니다.

파일 이름은 `나다주_타카하시선생님_2026-09-14~2026-09-20.png` 꼴입니다.
수업종류 범례가 아래에 붙어 있어 PNG만 봐도 색이 무슨 뜻인지 알 수 있습니다.

## Notion 스키마

### 나다주 학생

| 속성 | 타입 | 비고 |
| --- | --- | --- |
| `이름` | 제목 | |

### 나다주 수업

| 속성 | 타입 | 비고 |
| --- | --- | --- |
| `수업` | 제목 | 앱이 만들어 넣는 표시용. 앱은 읽지 않습니다 |
| `선생님` | 선택 | 타카하시 / 가와구치 / 김혜진 / 스도 / 표지연 |
| `학생` | 관계 | `나다주 학생` 을 가리킵니다 |
| `학생명` | 텍스트 | 관계가 끊겨도 시간표가 빈칸이 되지 않게 남기는 사본 |
| `수업종류` | 선택 | 본고사 / 면접 / 지유서 |

| `메모` | 텍스트 | |

필수 값(선생님·학생·수업종류·날짜·시작·종료)이 빈 행은 조용히 건너뜁니다.

## 함정들

- **Notion 통합 연결** — 통합을 만들기만 하면 아무 페이지도 못 봅니다.
  **두 데이터베이스 각각에서** `⋯ → 연결`로 통합을 추가해야 합니다.
  빠지면 404 → "데이터베이스를 찾을 수 없습니다"
- **조회 20초 캐시** — Notion API가 초당 3회 제한인데 한 번 그리는 데 쿼리가 두 벌 나갑니다.
  그래서 isolate 안에서 20초 캐시합니다. **앱에서 쓰면 캐시를 바로 버리므로** 앱으로 고친 건
  즉시 보입니다. Notion에서 직접 고친 게 안 보이면 `새로고침` 한 번 더
- **규칙이 두 벌** — 시각·날짜 계산과 블록 배치가 `src/model.ts` 와 `public/index.html` 에
  복제돼 있습니다. **한쪽만 고치면 화면과 저장이 어긋납니다**
- **요일 인덱스는 월=0 … 일=6** — JS `Date.getDay()`(일=0)와 다릅니다. 항상 변환하세요
- **시간축 컬럼 z-index** — `.timecol` 은 `z-index: 30`, 수업 블록은 `10`.
  이게 뒤집히면 가로 스크롤 시 시간축이 블록에 가려집니다
- **`.toolbar` 는 `display: flex`** — `hidden` 속성만으로는 안 숨겨져서
  `.toolbar[hidden] { display: none; }` 를 따로 두었습니다. 새 툴바를 추가할 때 주의
- **시간대는 `Asia/Seoul` 고정** (`src/model.ts` 의 `TIME_ZONE`). "오늘"이 여기서 갈립니다

## 설정

### 1. Notion 내부 통합

1. <https://www.notion.so/my-integrations> 에서 내부 통합을 만들고 토큰(`ntn_...`)을 복사
2. **나다주 학생** 페이지에서 `⋯ → 연결 → (통합 이름)`
3. **나다주 수업** 페이지에서도 똑같이 — **한쪽만 하면 안 됩니다**

### 2. 배포

```bash
git pull origin main
npm install

npx wrangler deploy
```

### 3. 시크릿

```bash
npx wrangler secret put SHARED_PASSWORD     # 앱 전체 접근용
npx wrangler secret put NOTION_TOKEN        # ntn_...
npx wrangler secret put NOTION_STUDENT_DB   # 277ed59b-a9d4-414c-8778-7f3b57eb963b
npx wrangler secret put NOTION_LESSON_DB    # bbcce3ec-bea3-4abd-adec-72c5f82620dd
```

확인:

```bash
curl -s -H "x-password: <비밀번호>" https://nadajoo.<계정>.workers.dev/api/data
# {"today":"...","teachers":[...],"kinds":[...],"students":[...],"lessons":[...]}
```

비밀번호 없이 부르면 `401` 과 함께 `{"error":"비밀번호가 올바르지 않습니다."}` 가 나와야 정상입니다.

### 로컬

`.dev.vars.example` 을 `.dev.vars` 로 복사해 값을 채우고 `npx wrangler dev`
(`.dev.vars*` 는 gitignore에 있습니다 — 커밋하지 마세요).

## 아직 안 한 것

- **쓰기 요청 횟수 제한 없음** — 공유 비밀번호 하나로 막고 있습니다.
  이 앱은 학생 연락처를 들고 있으니 Cloudflare Rate Limiting을 붙이는 게 좋습니다
- **드래그로 수업 길이 정하기** — 지금은 클릭 → 기본 2시간, 그 뒤 종료 시각을 고칩니다
- **반복 수업을 한꺼번에 옮기기** — 반복 등록은 되지만, 옮기거나 지울 땐 한 건씩입니다
- **선생님별 PNG 일괄 저장** — 지금은 보고 있는 시간표 한 장씩입니다
